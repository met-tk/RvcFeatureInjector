# Taketo · RVC Feature Injector 1.1.9

关闭 Cubase，运行单个完整离线安装程序 `RvcFeatureInjector-1.1.9-Setup.exe`，并同意 Windows 的管理员权限提示。安装器包含便携 Python/CUDA 运行库及 HuBERT/RMVPE 基础模型，约占 8.6 GB，建议预留 11 GB。**不附带任何歌姬模型，也没有内置歌姬预设。** 新实例 A/B 均为空，请使用 LOAD MODEL 导入自己的 `.pth`，需要检索时再使用 LOAD INDEX 导入匹配的 `.index`。

厂商、作者及安装程序发布者为 **Taketo**。

1.1.9 修复停止时启用捕获后，宿主提前发送的启播前滚近静音覆写旧声音的问题。只从停止时选定位置提交录音，逐采样裁剪跨界块；位置之后的真实静音仍会覆盖。播放中点击追加行为保持。保留纯湿声回放与相同输入缓存复用；点击 Logo 查看版本、build 和环境。

旧版已漏录的输入无法从旧缓存恢复，升级后请重新 CAPTURE 受影响区间再 GENERATE。重启插件会丢失当前捕获，捕获音频不随工程保存。

本产品只有 VST3 插件，没有独立的桌面应用。安装向导的两个目录分别是：

- **插件推理运行库（必需）**：默认 `C:\Program Files\Taketo\RvcFeatureInjector`。包含便携 Python、推理依赖、HuBERT/RMVPE、配置和卸载器，不是只放卸载程序，也不是第二个独立应用。
- **VST3 插件父目录**：默认 `C:\Program Files\Common Files\VST3`；安装器在其中创建 `RvcFeatureInjector.vst3`，供 Cubase 扫描。

安装器现在使用管理员权限，可写入默认系统 VST3 目录；运行库与插件父目录仍可分别选择。非标准 VST3 路径能否被扫描取决于宿主。安装后在 Cubase 的 VST 插件管理器重新扫描，并将 RVC Feature Injector 加入音频轨道的插入效果。1.1.2 及更早的当前用户安装需先卸载，再安装机器级 1.1.9；手动安装的同名旧插件应先移走，安装器不会接管未知目录。

静默安装可用 `/DIR="运行库目录\RvcFeatureInjector" /VST3DIR="VST3父目录"` 分别指定两个位置。升级沿用原目录；要迁移插件位置，请先卸载旧版，避免留下重复插件。已有手动安装的同名插件不会被接管，需要先自行移走。

已安装机器级 **1.1.3 至 1.1.8（含 DIAG1）** 时，保存工程并关闭 Cubase，直接运行 **1.1.9** 安装程序完成升级，无需先卸载。安装器复用原运行库目录，并从原安装记录恢复自选 VST3 目录；不要另选位置。用户自行增加且不与安装文件同名的模型及文件会保留。更新通过新版安装程序完成，没有独立在线更新器。升级后在 Cubase 中重新扫描插件。

**本版保留 1.1.5 的运行库复用，升级时读取现有文件并核对 SHA256。** 内容相同的文件不解压、不覆盖；缺失或内容损坏的文件自动安装修复，日期和版本号相同也会检查内容。读取约 8.6 GB 文件仍需时间，机械硬盘可能更慢。下载内容为**单个完整离线 EXE，无分卷**，安装时无需联网下载依赖，并非仅包含变化的小补丁。逐文件压缩让未变文件可以独立跳过，升级无需解压整个运行库。

本版包含 **APPEND CAPTURE**：先 **CAPTURE → 播放 → 停止播放**（或 STOP CAP／GENERATE）；需要补录时再 **定位 → APPEND CAPTURE → 播放 → 停止播放 → GENERATE**。连续播放中也可按 APPEND CAPTURE 开始追加。停止播放会自动结束录入，无需赶在 Cubase 光标返回前按 STOP APPEND；手动 STOP APPEND 仍可用。保留已有捕获，重叠部分覆盖；有数据时 **NEW CAPTURE** 用于清空重录。生成时不能开始捕获，捕获时先停止当前模式才能切换。捕获跨度最早到最晚最多240秒，包含中间空洞；超限拒收并保留已有数据。捕获音频不保存到宿主工程，重开工程仍需重新捕获与生成。

安装后插件的 `Contents\Resources\runtime-root.txt` 指向本次安装的独立运行库；不依赖原项目、旧解压目录或 D 盘参考环境。`RVC_RUNTIME_ROOT` 环境变量仍可由用户显式覆盖运行环境。无需全局安装 Python、CUDA 工具包或 VC++ 运行库，不更改 PATH，不注册服务；系统增加本程序的机器级卸载条目。x64 CPU 需支持 AVX2，CUDA 加速仍需要机器已有的兼容 NVIDIA 驱动。

`state-root.txt` 使用固定的用户目录占位符，由实际运行 Cubase 的用户解析为 `%LOCALAPPDATA%\Taketo\RvcFeatureInjector\state`。日志、Numba/CUDA 缓存和临时文件位于这里，普通权限运行的 Cubase 不会尝试写 Program Files，也不会让多个用户共享可写的推理缓存。

旧版仅复制 VST3 就能进行转换，是因为它会读取 `RVC_RUNTIME_ROOT`、`runtime-root.txt`，或最后尝试 `D:\RVC20260718Nvidia`。这不是单个 VST3 文件已经包含了完整 RVC 环境；Cubase 扫描和显示界面也不等于推理环境可用。

卸载前关闭所有使用本插件的 Cubase。通过 Windows「设置 → 应用 → 已安装的应用 → RVC Feature Injector」卸载，或运行推理运行库目录中的 `unins000.exe`，并同意管理员权限提示。卸载器记录实际 VST3 位置，按清单清理插件、推理运行库与经过专属标记验证的缓存；自行新增且不与安装文件同名的文件会保留。不要将需要保留的文件放进 `state`。宿主自己的扫描缓存和 Windows 自行维护的记录不属于本程序的卸载范围。

遇到占用文件、目录链接或归属异常会安全中止，不会强制结束 Cubase。升级中断后请重新运行安装程序修复；旧文件清单会恢复，但已覆盖的程序文件可能保留新版内容，不能保证恢复旧版运行状态。

SHA256 见同目录 `SHA256SUMS.txt`。此单个 EXE 只在安装时需要，正常卸载无需保留安装包。
