# RVC Feature Injector 1.1.9

修复 Cubase 停止时定位并启用 CAPTURE／APPEND CAPTURE 后，启播前滚输入覆盖旧音频的问题。实际现场数据中，首个播放块比起播光标提前 4,814 samples（44.1 kHz 下约 109 ms），其中前 4,813 samples 为近静音；旧版将其写入已捕获的正常长音，随后 Generate 便产生断层。

现在从停止时选定的位置开始提交捕获。光标之前的前滚块不覆盖旧音频、有效位或自动化；跨越该位置的块按采样裁剪，之后正常录入。此规则适用于新捕获和追加捕获，停止时移动光标会更新待录入位置。播放中直接按 APPEND CAPTURE 保持立即录入；宿主没有有效时间位置时保留原有回退行为。

不使用电平门限判断前滚。指定位置之后的真实静音、轻声或微小编辑仍会正常覆盖并重新转换。自动化按既有 10 ms 帧记录；跨起点的部分帧保留前段旧值，从下一完整帧记录本次参数。

保留 1.1.8 的纯湿声回放、捕获音频 RMS 参考和完全相同输入时的湿声复用。Logo/About 显示 1.1.9 / build 20261111.2 / Taketo，以及运行环境、模型和追加比较信息。正式版没有 DIAG1 的自动音频取证写入。

安装包仍为单个完整离线 EXE，无分卷；不附带歌姬模型，用户自行导入。机器级 1.1.3 至 1.1.8（含 DIAG1 补丁）可直接升级，沿用运行库和 VST3 目录；内容未变的 runtime 文件按 SHA256 跳过解压与覆盖。默认系统 VST3 目录、可选路径和精确卸载规则保持。

升级前保存工程并关闭 Cubase。捕获音频不随工程持久化，升级后重新 Capture / Generate。已经被旧版前滚覆盖的原录音不能由更新自动还原。
